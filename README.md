## Library Management System
Project Overview

The Library Management System is a desktop-based application developed using C#, .NET, and Windows Forms. The system was designed to replace the existing manual library management process at Moshi co-operative University (MOCU), located in Kilimanjaro, Tanzania.

This project was developed as a group academic project to demonstrate our practical understanding of C# programming, database connectivity, and Windows Forms application development.

## Objectives
To automate library operations that were previously handled manually

To reduce human errors in book management

To improve efficiency in book issuing, returning, and record keeping

To apply theoretical knowledge of C# and .NET in a real-world scenario

## Key Features

Add, update, and remove book records

Issue and return books

Input validation and error handling to prevent incorrect data entry

Database-backed storage for reliability and consistency

The system includes multiple validation checks to ensure that no errors occur when books are added, removed, issued, or updated in the database.

## Technologies Used
Programming Language: C#

Framework: .NET

User Interface: Windows Forms

Database: SQL Server (via connection string)

## Installation & Configuration

Clone or download the project from this repository

Open the project using Visual Studio

Update the database connection string to match your local or remote SQL Server

Important:
To run the system successfully, the connection string must be modified so that it connects to the correct database server.
